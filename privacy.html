プライバシーポリシー

最終更新: 2026-11-04

brain（以下「本アプリ」）は、Yuki 個人が使うためのアプリです。本アプリが扱う情報は次のとおりです。

  1. Google アカウントの認可情報: Google ドライブへのアクセス権（更新トークン）。Yuki の PC のなかだけに保存し、外部に送らない。
  2. Google ドライブのファイル: 本アプリが作成したスライドなど。Yuki のドライブのほかのファイルには触れない（権限 drive.file）。
  3. 作業の記録: 依頼の内容と結果。Cloudflare 上の管理画面と、Yuki の PC に保存する。

本アプリは、これらの情報を広告や販売の目的で使いません。第三者に提供しません。Google の API から得た情報は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従って扱います。

情報の削除を希望する場合は、下の問い合わせ先に連絡してください。ただし、Yuki の PC に残っているものは Yuki が削除します。

本ポリシーは、必要に応じて改定します。改定した場合は、このページで知らせます。

問い合わせ先: GitHub: yukiknk
